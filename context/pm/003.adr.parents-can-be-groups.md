---
title: Parents can be groups
status: accepted
created_on: 2026-08-27
---
## Context

How a document joins a group: by physical location alone, or by an
explicit reference. Groups have no frontmatter, so they cannot point at
children; only children can point at them.

## Decision

`parent:` may name a document (`{id}.{tag}.{slug}`) or a group
(`{id}.{slug}` — exactly the directory name). Frontmatter is
authoritative; file location is a derived projection that `pm tidy`
heals. A parentless document found inside a group directory is adopted:
tidy writes the group ref rather than evicting the file. All refs are
ID-authoritative — tag, slug, and ref form are hints only.

## Consequences

Easier: group membership is visible to referential integrity, so
"misplaced" and "intended" are distinguishable; renumbering a group
rewrites member refs mechanically; the natural drop-a-file-in-the-dir
gesture stays legal. Harder: a second ref form exists, and consumers
must resolve IDs against the scan instead of trusting the parsed form.

## Alternatives considered

- **Physical membership only** (being in the directory is the
  membership) — pros: no group ref format, nothing references
  directories so renames are free. Rejected: membership becomes
  invisible to integrity checking; a misplaced file and an intended
  member cannot be told apart, so tidy could verify nothing.
