## Problem

Documents accumulate. Done and abandoned documents pollute listings,
stale `idea` documents linger for months, and nothing distinguishes
"parked on purpose" from "forgotten". This is a human/agent discipline
problem — the tool should help without blocking.

## Candidate mechanisms (none committed)

- **`pm archive <id>`** — move a document to an excluded directory:
  invisible to list/ready/status, still counted for max-ID so IDs are
  never reused.
- **Git-derived staleness** — last-touch date from `git log -1` per
  file (no frontmatter field to maintain); `pm tidy` could surface
  documents untouched beyond a threshold and offer archiving.
- **`pm triage`** — interactive sweep over stale documents:
  keep / archive / done, one decision per document.
- **Default groups** — a reserved `000.backlog/` group (ID 0) created
  on the fly, so parked ideas have a home that listings can fold away.

The `archived` done-status on the note type was a first step in this
direction.
