Write the repository README for the open-source release: what pm is
(flat markdown documents + frontmatter, agent-first), the group/type
model, the type-guides mechanism, install and quickstart (`pm init`,
`pm new`, `pm ready`), and a pointer to the skills for Claude Code
users.

## Skills installation commands

For Claude Code users, the skills can be installed with `npx skills`
(from [vercel-labs/skills](https://github.com/vercel-labs/skills)):

```bash
# Interactive — prompts for agent and skill selection
npx skills add lud/pm

# Non-interactive, project-scoped
npx skills add lud/pm -a claude-code -y

# Non-interactive, global (available in all projects)
npx skills add lud/pm -a claude-code -g -y
```
