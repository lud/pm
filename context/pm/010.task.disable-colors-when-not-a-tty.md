---
title: Disable colors when not a TTY
status: new
created_on: 2026-09-29
---
`src/lib/cli.ts` output helpers (`success`, `warning`, `error`, …) emit ANSI
codes when stdout is piped, e.g. `pm new … | od -c` starts with `\033[92m`.
Agents see the raw escapes (`[92mCreated …[39m`) in every tool result.

Cause: ansis's auto-detection enables color from `COLORTERM=truecolor` alone,
which agent harnesses inherit from the user's terminal; unsetting `COLORTERM`
makes the output plain.

Done when colors are only emitted if the target stream is a TTY, `NO_COLOR`
disables them and `FORCE_COLOR` still forces them, with tests covering the
non-TTY case.
