Agents finish work without `pm done` (043, 049, 055 in aitx-pub) and later sessions find `pm current` pointing at a done doc (3 sessions).

- `pm current <id>` warns when it replaces a current document that is not done, suggesting `pm done <old>` if its work is finished.
- `pm current` and `pm status` warn when the current document is done or blocked, pointing to `pm ready`.

A Stop hook nudging `pm done` was considered and deferred: it would fire at the end of every turn while a doc is current, and keeping a doc open is often legitimate. (Claude Code's `stop_hook_active` input prevents the infinite loop, but not the nagging.)

Done when both warnings exist, are tested, and pm-guide mentions them.
