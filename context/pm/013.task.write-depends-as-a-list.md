`pm edit 22 --set depends:21` writes `depends: 21` (or `"021"`), and `pm tidy` then proposes `depends: [021.spec.…]`. Seen in 4 docs across 2 repos, and pm-guide teaches this exact command.

Done when `--set depends:…` (on `pm edit` and `pm new`) writes a list, accepting comma-separated values, with tests.
