`pm ready` silently hides documents waiting on `depends`: an implemented spec (043) was invisible and the user had to point it out. Done ancestors are also shown like roots, and agents can't tell context rows from ready rows.

Done when `pm ready` ends with a footer such as `2 waiting on depends, 1 blocked (--with-blocked to show)` when anything is hidden, and context-only ancestors are visually distinct from actionable rows.
