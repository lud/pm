`pm --help` lists command names with blank descriptions and shows the undocumented `next` alias; per-command help has no summary. Agents probed help 15+ times across sessions, mostly when pm-guide wasn't loaded.

Done when every command has a one-line description in `pm --help` and its own `--help`, and `next` is hidden from the list.
