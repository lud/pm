Small output issues seen in the session scan:

- [ ] `pm tidy` dry run ends with "Dry run. Use -f to apply changes."; an agent piping to `tail` reported "tree is tidy". Print a leading summary (`N changes pending` / `Nothing to do`) and use `--force` in the hint, as the skill does.
- [ ] `pm list --blocked` (and other empty listings, `pm ready` with nothing actionable) print nothing: print a one-line "No … documents" message.
- [ ] `pm info` is ~40 lines and gets piped through `head`, cutting types off: consider a compact form or `pm info <type>`.
