---
title: JSON output
status: idea
created_on: 2026-09-29
---

Every command gets a `--json` flag that prints structured output instead of text, so pm is truly pipeable for scripts and agents (e.g. `pm ready --json | jq`), and output formatting changes stop being breaking changes for tooling.

Open questions: one schema per command vs. shared document shape; whether errors and warnings also go to JSON (on stderr?); whether `pm read --json` includes the parsed frontmatter.
